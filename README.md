Simple Compiler written in C/C++ for COMP442 2024 Winter semester.

The lexer reads each token there are 3 types of tokens ids, ints, floats operators and keywords form there own types of tokens corresponding to the 
specific tokens actual lexeme.


to run the tests for the Lexer enter the following 
    
    make testlexer


to run the tests for the parser enter the following

    make testparser


to run the the tests for the AST generator, enter the following:
    
    make testastgen
